CodeAlpha CGPA Calculator
About the Project

This is a simple CGPA Calculator developed in C++ as part of my CodeAlpha internship.

The program calculates the student's CGPA based on the entered course grades and credit hours.

Features
Calculate CGPA
Accept course grades
Accept credit hours
Display the calculated CGPA
Simple and user-friendly console interface
Technology Used
C++
How to Run
Download or clone this repository.
Open the C++ source file in a C++ compiler or IDE.
Compile the program.
Run the program.
Enter the required course and grade information.
